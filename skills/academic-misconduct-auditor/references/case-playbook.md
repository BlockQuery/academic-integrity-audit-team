# 举报实战核查手册

> 本章来自真实实名举报案件的复盘，全部案例细节已匿名化处理。它解决一个具体问题：**为什么有的举报材料事实很硬却被退回，有的材料看起来平淡却能立案。**
>
> 结论先给：受理机关看的不是"这个人有多可疑"，而是**"我能不能在半小时内独立验证这件事，并且找到一条明确的规定说他违反了什么"**。

---

## 一、三链结构：举报材料的骨架

一份能立案的材料必须同时具备三条链。缺任何一条，材料会被要求补正，时间成本按月计。

| 链 | 内容 | 缺失后果 |
|---|---|---|
| **事实链** | 谁、哪篇论文、标了什么、什么时间、原文第几页 | 被认定为"主观质疑" |
| **规则链** | 违反了哪份文件的哪一条（名称 + 条款 + 现行版本） | "无法认定违规" |
| **责任链** | 该事实由谁负责（一作/通讯/项目负责人/依托单位） | "无法确定责任主体" |

**写法要求**：每个举报事项单独成节，每节内部按"时间—行为—证据—规则—责任"五段推进。禁止把十件事揉成一段。

**反例**（常见但无效）：
> "该同志长期学术不端，大量论文存在造假，请查处。"

**正例**：
> 2021 年 3 月，被举报人以第一作者身份在《XX 杂志》发表论文（DOI 10.xxxx/xxxxx，附件 1）。该文首页脚注标注"国家自然科学基金项目（批准号 XXXXXXXX）"。经科学基金共享服务网查询，该批准号对应项目负责人为 A，依托单位为 B 单位，执行期 2016-01 至 2019-12（附件 2）。被举报人既非负责人亦非参与人，且论文发表时间晚于项目结题 15 个月。上述行为违反《国家自然科学基金资助项目研究成果管理办法》关于成果标注真实性的要求（附件 3）。

差别在哪：后者每一句都能被独立验证，且指向一个具体的人和一个具体的规则。

## 二、基金标注：最容易出硬结论的一维

基金标注是学术不端核查里**证据门槛最低、最容易形成硬结论**的方向。原因很简单：批准号是公开可查的唯一标识，对不上就是对不上，没有解释空间。

### 2.1 五要素核验表

逐篇打开 PDF 首页脚注，把每个基金号抄下来，核这五件事：

| # | 核验项 | 数据来源 | 不符的含义 |
|---|---|---|---|
| 1 | 批准号是否真实存在 | 科学基金共享服务网 kd.nsfc.gov.cn | 查无此号 → 虚假标注 |
| 2 | 项目负责人是否为本人 | 同上 | 非本人 → 需说明是否为参与人 |
| 3 | 依托单位是否为目标单位 | 同上 | 单位不符 → 需说明任职变动 |
| 4 | 执行期是否覆盖论文时间 | 项目起止年月 vs 论文投稿/发表年月 | 早于起始年 → 时间穿越；晚于结题 2 年 → 需说明 |
| 5 | 内容是否属于该项目范围 | 项目摘要/关键词 vs 论文主题 | 明显无关 → 成果凑数 |

**核查表模板**

| 论文 | DOI | 标注的批准号 | 项目负责人 | 依托单位 | 执行期 | 论文年月 | 内容相关 | 结论 |
|---|---|---|---|---|---|---|---|---|

「结论」列只能填：一致 / 需说明 / 不符。不填"造假"。

### 2.2 三种典型错标形态

**形态一：张冠李戴**
论文标注的是他人项目的批准号。判断要点是"负责人非本人 + 本人非参与人"同时成立。若本人是参与人，标注合规。

**形态二：时间穿越**
论文发表时间早于项目起始年月。这是最硬的一种——立项之前的研究不可能由该项目资助。注意留出合理误差：项目起始当年发表的论文通常可接受（年初立项、年中投稿）。

反向可能：批准号年份段与项目实际立项年不一致（如延期项目、连续资助项目），需以共享服务网记录为准，不能只凭号码推断。

**形态三：一稿多报**
同一篇论文被列入多个项目的结题成果。核查方法是把每个项目的结题成果清单拉出来做交叉比对，看是否有同一 DOI 重复出现。跨项目比对时要注意：联合资助、子课题共享成果是允许的，但同一篇论文同时作为两个独立项目的主要成果交账，属于重复计算。

### 2.3 关于批准号的读法（仅作辅助，不作判据）

国家自然科学基金批准号通常为 8 位数字，常见规律是：首位或前两位含学部/类型信息，中间两位对应立项年份后两位，末几位为顺序号。例如 `819xxxxx` 常见于 2019 年立项的医学科学部项目。

**但这条规律不能当判据。** 不同学部、不同项目类型（面上、青年、地区、重点、联合基金）编码规则不同，延期与连续资助也会打破年份对应。**一切以共享服务网查到的记录为准**，号码推断只能用来发现"可疑"，不能用来下结论。

### 2.4 元数据的陷阱

OpenAlex 的 `funders` 字段只有资助机构名，**没有批准号**；Crossref 的 `funder` 有时有 award 编号但也常缺失。

这意味着：**任何基于元数据得出的"基金标注合规/不合规"结论都是不可靠的**。必须打开原文。这也是为什么报告里 D5 维度的证据等级永远低于 D2、D3——它依赖人工抄录。

## 三、虚假结题：三条交叉核查线

结题报告虚列成果是科研经费案件的高频问题。核查不是看单篇，是看**三方对照**：

```
项目 A 的结题成果清单  ←→  论文原文实际标注  ←→  论文主题与项目内容
```

三条线同时不吻合，才构成"虚列"的合理线索：

| 线 | 不吻合的表现 | 单独成立吗 |
|---|---|---|
| 清单里有、原文没标 | 结题报告列了该论文，但论文脚注没标这个项目 | 弱（可能是漏标） |
| 原文标了、清单没有 | 通常是遗漏，不构成问题 | 否 |
| 主题与项目内容无关 | 项目做示例学科材料，论文写肿瘤基因组学 | 中（需结合前两条） |
| 时间在项目期外 | 论文早于立项或晚于结题 2 年以上 | 强 |

**输出格式**：做成一张矩阵表，一眼能看出哪些论文是"三重不吻合"。

| 论文 | 在结题清单 | 原文标注 | 主题相关 | 时间在期内 | 不吻合项数 |
|---|---|---|---|---|---|

不吻合项数 ≥3 的，才是值得单列的线索。

## 四、APC 与版面费：公开数据能给到的极限

版面费问题（虚开发票、套取经费）**无法从公开数据证明**——发票、报销单、项目账目都不公开。但可以给线索，供后续核查方向：

| 线索 | 观察方法 | 指向 |
|---|---|---|
| APC 与期刊层级严重不符 | 期刊官网 APC 页面 vs 该刊影响力/收录状态 | 高额支出低质产出 |
| 集中向同一出版商投稿 | 出版社分布统计，单一家占比 >60% | 可能存在打包合作 |
| 短期内集中发表 | 年度分布出现尖峰，且全为 OA | 批量操作 |
| 全部论文均 OA 且均收费 | OA 比例 100% + APC 普遍偏高 | 经费驱动型发表 |
| 同一批论文的投稿周期异常一致 | 原文 received/accepted 日期 | 代投代写 |

**表述纪律**：这一节的所有结论只能写成"建议核查该单位的版面费支出与报销凭证"，**绝不能写成"存在虚开发票"**。后者是需要账目证据的定性，超出公开数据的证明能力。

## 五、系统性违规：从单篇到模式

单篇疑点很容易被解释为"疏忽""挂名惯例""学生操作"。真正让案件成立的是**同一模式在不同论文中重复出现**。

### 五种可量化的重复模式

1. **基金号复用**：同一批准号挂在 N 篇主题互不相关的论文上
2. **作者池固定**：同一组 3-5 人反复出现，且位次轮换
3. **期刊集中**：80% 成果集中在 ≤3 本刊
4. **图件复用**：同一 Western blot / 显微图在不同论文中呈现相同纹理
5. **时间聚集**：某一年度产出是年均的 3 倍以上

### 做法：做矩阵，看对角线

把这五个维度做成一张"论文 × 特征"矩阵，标记每篇命中的特征。单篇命中 1 项不算什么，**同一批论文同时命中 3 项以上**，才是系统性问题的形态。

```
论文  | 基金复用 | 作者池 | 期刊集中 | 图件复用 | 时间聚集 | 命中数
P01   |    ✓    |   ✓   |    ✓    |    ?    |    ✓    |  4
P02   |    ✓    |   ✓   |    ✓    |    ?    |    ✓    |  4
P03   |    ✓    |   ✓   |         |    ?    |         |  2
```

这张表比十页文字描述有说服力。

## 六、30 分钟验证原则

每个事实点，受理机关应当能在 30 分钟内独立验证。做不到的，要么补材料，要么删掉。

自检清单：

- [ ] DOI 能在 doi.org 解析到正确页面？
- [ ] 引用的页码、图号与原文一致？
- [ ] 基金批准号能在共享服务网查到，且截图带查询时间？
- [ ] 引用的规则是**现行有效**版本？年份标注了吗？
- [ ] 网页证据有 URL + 访问日期？做了存档（如 web.archive.org）？
- [ ] 中文论文给了 CNKI/万方的篇名与年期，而不只是标题？
- [ ] 每个"不符"都能指出具体差在哪（谁 vs 谁、哪年 vs 哪年）？

任何一项打不了钩，该条事实在正式材料里就要降级为"待核实"。

## 七、常见退回原因（反向清单）

按发生频率排序，来自真实反馈：

| 原因 | 表现 | 修法 |
|---|---|---|
| 只有质疑没有证据 | "该文数据明显不可靠" | 指出具体图号、具体数字矛盾 |
| 证据无出处 | 截图但没有 URL/页码 | 补链接与访问时间 |
| 规则引用失效 | 引了已废止的办法，或版本不对 | 核现行文本，标年份 |
| 把推测写成认定 | "系代写""明显造假" | 改为"存在与代写模式一致的特征" |
| 一事多议 | 十几条混在一起，核心被稀释 | 拆成一事一节，按严重度排序 |
| 牵连无关人员 | 把学生、合作者一并举报 | 只列有直接责任的人 |
| 走错机关 | 论文问题寄给纪检 | 按受理范围分送（见下） |
| 重复提交 | 同一材料反复寄送 | 等受理编号，按流程补充 |

### 受理范围对照

| 问题类型 | 受理机关 |
|---|---|
| 基金项目成果造假、虚假结题 | 国家自然科学基金委员会监督委员会 |
| 论文本身的数据/图片问题 | 期刊编辑部、出版伦理委员会（COPE） |
| 作者层面的学术不端 | 所在单位学术委员会、科研诚信管理部门 |
| 骗取科技经费 | 科技部科研诚信建设联席会议、审计部门 |
| 公职人员违纪违法 | 纪检监察机关 |

多渠道并行时，各渠道材料的事实部分必须完全一致，不得一处说 A、一处说 B。

## 八、从审计报告转举报材料

审计报告是内部底稿，举报材料是对外文书。两者不能直接等同，但可以映射：

| 审计报告章节 | 转为举报材料 |
|---|---|
| §3.5 基金合规（D5） | 举报事项一：基金标注不实 |
| §3.4 学术规范（D4） | 举报事项二：数据/图片问题（若有硬证据） |
| §4 信号汇总表 | 附件清单与索引 |
| §5 剔除清单 | **主动说明**：已排除的误并论文（体现严谨，极加分） |
| §2 成果画像 | 被举报人学术产出概况 |
| §7 附录 A/C/D | 证据附件 1、2、3 |

**特别注意**：把"剔除清单"主动写进材料，是提高可信度最有效的一招。它告诉受理机关：这个举报人做过自我纠错，不是逢文必反。

## 九、时间与节奏

| 阶段 | 常见周期 | 注意事项 |
|---|---|---|
| 提交到受理告知 | 2 周–2 个月 | 保留受理编号与邮寄凭证 |
| 初步核查 | 3–6 个月 | 期间可能要求补充材料，一次补齐 |
| 结论告知 | 6–12 个月 | 逾期可依程序询问进展 |
| 复查/复核 | 视机关规定 | 一般不接受"新证据"以外的重复申请 |

**调查期间不要公开发布。** 网络曝光会改变案件性质，也可能被认定为干扰调查程序，反而削弱处理力度。这一条在实务中反复被验证。

---

## 十、本手册的边界

- 本章提供的是核查方法与取证规范，**不是法律意见**。涉及名誉权、隐私、诉讼策略的，须咨询执业律师。
- 规则条款以发布机关官网现行文本为准。本章只给规则名称，不给条款号——条款号会随修订变化，抄错一条足以让整份材料失去可信度。
- 所有匿名化案例仅保留方法论，不指向任何具体个人或单位。
