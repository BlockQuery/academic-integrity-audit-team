# 表述纪律、法律边界与举报材料规范

这份文档的作用：让报告在被对方律师、被调查单位、上级主管部门逐字审读时站得住。学术审计最常见的失败不是"没查出来"，而是"查出来的东西因为表述越界而整体失效"。

---

## 一、三条法律红线

### 1. 名誉权

《民法典》第 1024 条：民事主体享有名誉权，任何组织或个人不得以侮辱、诽谤等方式侵害他人名誉权。

第 1025 条给出公益监督的免责空间：为公共利益实施新闻报道、舆论监督等行为影响他人名誉的，不承担民事责任——**但**有三种例外：
1. 捏造、歪曲事实；
2. 对他人提供的严重失实内容未尽到合理核实义务；
3. 使用侮辱性言辞等贬损他人名誉。

第 1026 条列出认定"合理核实义务"的考量因素：内容来源可信度、对明显可能引发争议的内容是否做了必要调查、内容的时限性、与公序良俗的关联性、受害人名誉受贬损的可能性、核实能力与成本。

**对审计报告的直接约束**：
- 每条指控必须有可指认的来源（DOI、URL、数据库记录），这对应"来源可信度"。
- 有争议的判断必须写明核实过程（查了哪些库、为什么排除其他可能），这对应"必要调查"。
- 不得使用"学术骗子""造假惯犯""惯犯""流氓"等词，这对应"侮辱性言辞"。
- 不得把"疑似"写成"就是"，这对应"捏造、歪曲事实"。

### 2. 个人信息

《个人信息保护法》允许处理**已公开**的个人信息，但要求"合理"且不得侵害个人重大利益（第 27 条）。学术成果、任职单位、职称属公开的职业信息；家庭住址、身份证号、私人通讯、健康状况、家庭成员信息不属于审计范围。

审计报告中不得出现：
- 身份证号、手机号、家庭住址、私人邮箱
- 家庭成员及其工作单位
- 未经公开的健康信息、婚姻状况
- 私人聊天记录截图

需要指认身份时，用"姓名 + 单位 + 职称 + ORCID"即足够。

### 3. 诬告陷害

《刑法》第 243 条诬告陷害罪、以及《治安管理处罚法》关于诽谤的规定。核心要件是"捏造事实"。基于公开数据的**有依据的质疑**不构成诬告，但把推测写成事实、或明知不实仍提交，则风险极高。

**操作守则**：报告中每一个 C 档结论，必须能回答"如果对方要求我出示依据，我能不能立刻拿出"。拿不出的一律降为 B 或 D。

## 二、表述对照表

### 禁止 → 允许

| 禁止表述 | 问题 | 允许表述 |
|---|---|---|
| 学术造假 | 定性，越权 | 论文数据存在无法解释的重复，建议核查原始记录 |
| 论文代写 | 无法由公开数据证明 | 该论文存在与代写模式一致的特征（列举），需本人说明 |
| 学术骗子 | 侮辱性 | （删除，不作人格评价） |
| 惯犯 | 侮辱性 + 推断 | 该现象在其 2019—2023 年的 5 篇论文中重复出现 |
| 明显是买的 | 主观推断 | 该论文的署名作者与实验条件不相匹配，需核实贡献 |
| 水刊 | 贬义 + 无标准 | 该刊未被 SCIE/Scopus 收录，且未列入北大核心 |
| 毫无疑问 | 绝对化 | 在本次检索范围内未见反证 |
| 众所周知 | 无来源 | 据《××名单》（20XX 年版） |
| 据说/据了解 | 无来源 | （删除，或补来源） |
| 他肯定知道 | 推测他人主观 | 该论文的通讯作者为其本人，按惯例对数据真实性负主要责任 |

### 三层标注的写法

```
【事实】该论文（DOI 10.xxxx/xxxxx）图 3A 与作者 2021 年另一篇论文
（DOI 10.yyyy/yyyyy）图 2B 在相同放大倍数下呈现相同的背景噪点分布。

【推演】两图为同一原始图像的可能性较高。若成立，则同一组实验数据
被用于支撑两篇不同论文的结论。

【推测】需调取两篇论文的原始图像文件与实验记录方可确认。目前无法
排除"作者复用对照图"这一较弱解释。

【反向证据】该作者在同期其他论文中提供了完整的原始数据补充材料，
与"系统性伪造"的假设不完全一致。
```

四段齐全才算合格条目。缺【反向证据】的条目不得进入 C 档。

## 三、证据分级与举证要求

| 级别 | 证据类型 | 对方能否轻易反驳 | 报告中的用法 |
|---|---|---|---|
| 一级 | 官方数据库记录（基金委、期刊官网、撤稿声明） | 难 | 可直接作为事实陈述 |
| 二级 | 论文原文（PDF、图表、脚注） | 难 | 可直接作为事实陈述，须附页码/图号 |
| 三级 | 第三方数据库元数据（OpenAlex、Crossref、知网） | 较易（数据错误） | 须注明"据 XX 数据库，建议以原文核对" |
| 四级 | 算法推断（主题分类、相似度、产量统计） | 易 | 只能作线索，不得单独支撑结论 |
| 五级 | 公开质疑（PubPeer、论坛帖） | 易 | 只能写"存在公开质疑"，不得作为事实 |

**规则**：C 档结论至少需要一条一级或二级证据 + 一条独立的三级证据。

## 四、举报材料规范（若委托用途为举报）

### 结构

1. **被举报人基本信息**：姓名、单位、职务/职称、研究方向。（不写身份证号、住址）
2. **举报事项**：一事一节，每节一句话概括 + 展开。不要把十件事混成一段。
3. **事实与证据**：每节按"时间—行为—证据"三段写。证据用附件编号引用（附件 1、附件 2）。
4. **规则依据**：引用具体规则名称与条款（如《国家自然科学基金项目科研不端行为调查处理办法》第 X 条），**条款号必须核对原文**。
5. **请求事项**：请求核查什么、依据什么规则处理。写"请求依法核查"，不写"请求开除"。
6. **附件清单**：编号、名称、页数、来源。
7. **举报人信息与联系方式**：实名举报须填写。

### 硬性要求

- **一事一议**：每个举报事项独立成立或不成立，不搞"打包定罪"。
- **可核查**：每个事实点都能被受理机关在 30 分钟内验证（给 DOI、给页码、给数据库截图）。
- **区分事实与意见**：意见部分明确标注"举报人认为"。
- **不牵连**：不把无关人员、无关年份的问题写进来充数，这会稀释核心指控。
- **不预设结论**：写"涉嫌""请求核查"，不写"已经构成"。
- **留副本**：所有提交材料自留完整副本与提交凭证（受理编号、邮寄单号、签收记录）。

### 受理渠道对应

| 情形 | 渠道 |
|---|---|
| 基金项目成果造假 | 国家自然科学基金委员会监督委员会 |
| 论文本身的问题 | 发表期刊的编辑部 / 出版伦理委员会（COPE） |
| 作者所在单位层面的学术不端 | 所在高校/医院学术委员会、科研诚信管理部门 |
| 涉嫌骗取科技经费 | 科技部科研诚信建设联席会议、审计署 |
| 公职人员违纪 | 纪检监察机关 |

多渠道并行时，各渠道材料应保持一致，不得一处说 A 一处说 B。

## 五、自检清单（交付前逐项打勾）

- [ ] 报告中是否出现"造假""代写""骗子""惯犯""水刊"等定性或贬义表述？
- [ ] 每个 C 档结论是否有 ≥1 条一级/二级证据 + ≥1 条独立三级证据？
- [ ] 每个 B 级以上疑点是否都写了【反向证据】段？
- [ ] 是否写明了数据源、检索式、检索日期、命中数？
- [ ] 是否列出了覆盖盲区（尤其"代写无法由公开数据证明"）？
- [ ] 是否剔除了 D0 判定为误并的论文，并保留了剔除清单？
- [ ] 是否包含身份证号、住址、家庭成员等非公开信息？（有则删除）
- [ ] 是否出现"应撤销职称""应开除"等越权处分建议？
- [ ] 基金号是否逐一在基金委数据库核对过，而非依赖元数据？
- [ ] 结论是否落在四档之内（未发现异常/需说明的疑点/高度可疑/证据不足）？
- [ ] 是否保留原始 JSON 与检索截图，可供复核？
