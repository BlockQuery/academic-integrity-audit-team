# 六维审核评分卡

每个维度按 A/B/C/D 四档判定。**C 档需要至少两条相互独立的信号**，单条信号最高只能到 B。这条规则是为了防止"一个巧合被写成结论"。

---

## D0 身份一致性（前置维度，不通过则整体重算）

**为什么放在最前**：OpenAlex、Google Scholar、Scopus 的作者档案都存在错误合并。误把他人论文算到目标头上，会直接产出"跨专业""高产""主题断裂"等一连串假阳性，这是学术审计里最经典的事故。

### 核查点

| 编号 | 核查内容 | 方法 |
|---|---|---|
| D0-1 | 同一 author ID 下是否存在与其余成果零交集的论文 | 脚本 `identity_check.isolated_work_ids` |
| D0-2 | 这些论文的署名单位是否为目标单位 | 打开原文看作者 affiliation |
| D0-3 | 署名邮箱、ORCID 是否为本人 | 原文脚注 / 通讯作者信息 |
| D0-4 | 是否存在同名不同人（如临床医生与基础研究者同名） | 中文库交叉检索，看研究方向 |

### 判定

- **A**：全部论文可归属，无孤立项。
- **B**：1–2 篇存疑，但署名单位一致。
- **C**：≥3 篇与其余成果完全无交集，且署名单位非目标单位 → 判定为档案误并，**必须剔除后重算**，并在报告中单列"剔除清单"。
- **D**：原文无法获取（无 DOI、无全文），无法核实。

### 常见误判

- 把"跨机构合作论文"当成误并。判据是**合作者是否有交集**，不是"单位是否只有一家"。
- 把作者的曾用名/英文名变体当成两个人。先查 `display_name_alternatives`。
- 忽略中文库里的同名作者。中文姓名重名率远高于拼音，反过来也会漏检。

## D1 产出节奏与规模

### 核查点

| 编号 | 核查内容 | 阈值参考 |
|---|---|---|
| D1-1 | 年度产出分布 | 某年 ≥ 中位数×3 且绝对量 ≥5 → 关注 |
| D1-2 | 峰值年的论文是否为同一批数据拆分 | 看题目相似度、样本量、图表复用 |
| D1-3 | 是否存在长期空白后突增 | 常见于读博/晋升节点，本身不构成异常 |
| D1-4 | 年均产出与学科常规是否匹配 | 临床医学 2–5 篇/年属正常；>10 篇/年需解释 |

### 判定

- **A**：产出曲线平滑，与学科常规一致。
- **B**：存在 1 个峰值年或明显空白，但有可解释原因（晋升、读博、团队组建）。
- **C**：峰值年论文存在数据拆分迹象（同一批样本发多篇、图表重复），或多年度持续异常高产且无团队支撑。
- **D**：无法获取投稿/录用时间，不能判断节奏。

### 常见误判

- **综述与论著混算**。综述产出快，一个作者一年 5 篇综述完全正常。必须按 `type` 拆分统计。
- **会议摘要计入论文**。国际会议的 abstract 常被计入"发表论文数"，虚增 2–3 倍。
- **中文刊 + 英文刊同内容双发**。这是重复发表问题（归 D4），但在 D1 里会表现为"高产"。先去重再统计。

## D2 专业相关性（是否超出专业）

### 判定基准的选择（关键）

**不要用"最大 field 占比"当基准**。OpenAlex 对中文临床期刊的分类很粗，示例学科临床研究常被判为 Medicine 而非 Dentistry，导致"主领域"判错，进而把正常的本行工作算成"跨专业"。

正确做法是按三层看：

1. **一级学科域（domain）**：Health Sciences / Life Sciences / Physical Sciences / Social Sciences。跨 domain 才是实质性跨度。
2. **主题（topic）**：看是否能串成一条技术主线。例：示例学科临床 → 颅面影像 → 影像算法 → 深度学习分割，这是**一条主线**，不是四个专业。
3. **合作者结构**：跨域论文中，本人是主导（一作/通讯）还是参与者（中间位次）？参与者身份跨域很正常。

### 核查点

| 编号 | 核查内容 | 说明 |
|---|---|---|
| D2-1 | 跨 domain 论文占比 | ≥30% 触发关注 |
| D2-2 | 跨域论文是否存在技术主线 | 看 topic 序列，不看 field 标签 |
| D2-3 | 跨域论文中本人位次 | 中间位次 = 参与，正常 |
| D2-4 | 跨域论文的合作者是否为目标单位的对应科室 | 有对口合作者 = 正常交叉 |
| D2-5 | 是否出现与本人训练背景完全无关的领域（如示例学科医生独立发表肿瘤基因组学） | 这是最需要解释的情形 |

### 判定

- **A**：成果集中于 1–2 个 domain，或跨域但主线清晰、合作者对口。
- **B**：跨 2 个 domain，主线可解释但证据不充分。
- **C**：出现与训练背景无关的领域，且本人在该论文为**第一/通讯作者**，且无对口合作者，且该论文与本人其他工作无任何引用或主题关联。四项同时成立才到 C。
- **D**：论文主题标签缺失，无法判断。

### 常见误判

- **把"学科标签分散"当异常**。分类器噪声，不是作者问题。
- **把临床医生的基础研究当越界**。很多临床医生有基础医学训练或合作实验室，这是常态。
- **忽略"挂名"与"主导"的区别**。中间位次的跨域论文几乎不构成问题；一作/通讯才需要解释。

## D3 期刊与发表渠道质量（水刊判定）

### 核查点

| 编号 | 核查内容 | 数据来源 |
|---|---|---|
| D3-1 | 是否在《国际期刊预警名单》 | 中科院文献情报中心年度名单（以当期官方版本为准） |
| D3-2 | 是否被 SCIE / ESCI / Scopus 收录 | Web of Science Master Journal List、Scopus Sources |
| D3-3 | 是否为正规 OA（DOAJ 收录） | doaj.org |
| D3-4 | 影响因子来源是否真实 | JCR 官方；警惕 "Index Copernicus" "ISRA" 等非 JCR 指标冒充 IF |
| D3-5 | 审稿周期是否异常短 | 期刊官网 received→accepted 天数；< 14 天需警惕 |
| D3-6 | APC 与期刊层级是否匹配 | 期刊官网 APC 页；低影响力刊收 3000 美元以上需核查 |
| D3-7 | 是否大量发表于特刊（Special Issue） | 期刊官网特刊页面、客座编辑名单 |
| D3-8 | 编委名单是否可核实 | 编委是否真实任职、是否有本人不知情被列名 |
| D3-9 | 中文刊：是否为核心期刊 | 北大核心、CSCD、科技核心（统计源）；警惕"增刊""专刊""论文集" |
| D3-10 | 是否同一出版社旗下多刊轮发 | 出版社集中度分析 |

### 判定

- **A**：全部论文发表于被正规索引收录的期刊，无预警名单命中。
- **B**：存在 1–2 篇发表于非核心/未被索引期刊，但期刊本身无掠夺性特征。
- **C**：命中预警名单，或多篇发表于具备掠夺性特征（虚假 IF、承诺极速审稿、编委造假）的期刊，或全部成果集中在同一本低质刊。
- **D**：期刊信息缺失，无法核实收录状态。

### 常见误判

- **"非 SCI 就是水刊"**。中文核心期刊、行业内正规刊大量不是 SCI，这是学科生态，不是质量问题。
- **"OA 就是水刊"**。Nature Communications、PLOS Medicine 都是 OA。判断标准是收录状态与审稿规范，不是是否收费。
- **预警名单跨年混用**。名单逐年调整，必须注明版本年份。用旧名单判新论文会误伤。
- **把综述刊、病例报告刊一律视为低质**。部分病例报告刊是正规学术交流渠道。

## D4 学术规范（代写 / 论文工厂 / 重复发表 / 撤稿）

**这一维必须最克制。** 代写与论文工厂在公开数据里**无法被直接证明**，只能通过结构性指纹推断。任何指向"代写"的表述都必须是"存在与代写模式一致的特征"，不得写成"系代写"。

### 核查点

| 编号 | 核查内容 | 方法 |
|---|---|---|
| D4-1 | 撤稿记录 | Retraction Watch 数据库、期刊官网、PubPeer |
| D4-2 | 图片重复使用 | 同一作者多篇论文的 Western blot / 显微镜图 / 流式图逐对比对；ImageTwin、Proofig（付费）或人工比对 |
| D4-3 | 文本重合 | Google Scholar 精确句子检索；同作者论文间段落比对 |
| D4-4 | 一稿多投 / 重复发表 | 同标题不同刊、不同 DOI 但摘要高度重合；中英文双版是否互相引用声明 |
| D4-5 | 伦理批号真实性 | 论文标注的伦理批号是否能对应到机构伦理委员会；批号格式是否规范 |
| D4-6 | 临床试验注册号 | 标注的注册号（ChiCTR / NCT）是否真实存在、注册时间是否早于入组 |
| D4-7 | 样本量与统计一致性 | 各组 n 值与总样本量是否对得上；表格与正文数字是否一致 |
| D4-8 | 作者贡献声明 | 是否缺失；多篇论文的贡献声明是否逐字雷同 |
| D4-9 | 参考文献异常 | 大量引用与主题无关文献、集中引用同一小圈子、引用不存在文献 |
| D4-10 | 论文工厂指纹 | 模板化标题结构、异常规整的图表排版、作者邮箱与机构不匹配、非专业作者署名专业论文、细胞系错配 |
| D4-11 | 数据可得性 | 是否声明数据可用；被要求提供原始数据时是否能提供（此项通常需正式函询） |
| D4-12 | 作者署名异常 | 同一批次论文作者组合高度重复、无实质贡献者挂名、买卖署名嫌疑 |

### 判定

- **A**：未发现上述任一异常。
- **B**：存在 1 项弱信号（如贡献声明缺失、参考文献异常），可由疏漏解释。
- **C**：存在 ≥2 项相互独立的强信号（图片重复 + 伦理批号无法核实 + 审稿周期 <7 天），或已有撤稿记录且撤稿原因为数据问题。
- **D**：无法获取全文，无法核查图片与数据。

### 常见误判

- **把图片"看起来像"当重复**。必须做像素级或区域比对，注明具体图号与区域。不同实验的相似构图很常见（如相同放大倍数的组织切片）。
- **把语言风格差异当枪手痕迹**。非英语母语作者的润色服务是合规的，语言服务 ≠ 代写。
- **把高自引当不端**。自引是学术传播常态，除非自引率异常（>50%）且有操纵意图。
- **仅凭"审稿快"定性**。部分正规刊确实流程快，需结合其他信号。
- **忽略撤稿原因的分类**。撤稿可能是作者主动纠错（诚实行为）、编辑错误、或数据造假，性质完全不同。必须读撤稿声明原文。

## D5 基金合规（国家自然科学基金为重点）

### 规则依据（引用名称，不臆造条款号）

- 《国家自然科学基金条例》
- 《国家自然科学基金项目科研不端行为调查处理办法》
- 《国家自然科学基金资助项目研究成果管理办法》
- 各类项目管理办法中关于"研究成果标注"的要求

具体条款以基金委官网现行文本为准，报告中引用时写规则名称 + 现行版本年份，不写具体条号，除非已核对原文。

### 核查点

| 编号 | 核查内容 | 方法 |
|---|---|---|
| D5-1 | 基金号是否真实存在 | 科学基金共享服务网 `kd.nsfc.gov.cn` 按批准号查询 |
| D5-2 | 项目负责人是否为本人 | 同上，查项目负责人姓名 |
| D5-3 | 依托单位是否为目标单位 | 同上，查依托单位 |
| D5-4 | 项目执行期是否覆盖论文发表时间 | 项目起止年月 vs 论文年月；结题后 1–2 年内发表仍属合理产出期 |
| D5-5 | 论文主题是否属于该项目研究内容 | 项目摘要/关键词 vs 论文主题 |
| D5-6 | 单篇标注基金数量是否合理 | ≥3 个触发关注；需核对是否为联合资助 |
| D5-7 | 是否标注了不存在或错误的基金号 | 逐位核对批准号；常见错误：年份段写错、学部代码错 |
| D5-8 | 是否将他人项目标注为自己的 | 项目负责人非本人且本人非参与人 → 高风险 |
| D5-9 | 结题报告是否虚列论文 | 结题报告所列论文是否真实存在、是否实际标注了该项目 |
| D5-10 | 同一论文是否重复计入多个项目结题 | 跨项目比对论文清单 |
| D5-11 | 资助类别与论文水平是否匹配 | 面上/青年/重点项目的产出预期不同 |

### 判定

- **A**：全部基金标注可核实，负责人与单位一致，执行期覆盖，主题相关。
- **B**：存在标注不规范（如漏写批准号、执行期边界模糊），但项目真实且本人为负责人/参与人。
- **C**：出现下列任一情形——标注的基金号查无此项目；项目负责人非本人且本人非参与人；论文主题与项目内容明显无关却被列为结题成果；同一论文被多个项目重复交账。
- **D**：无法获取论文原文脚注，或基金委数据库无该记录但可能有未公开项目。

### 常见误判

- **用元数据代替原文**。OpenAlex 的 `funders` 只有机构名没有批准号，Crossref 的 funder 信息常缺失。必须看论文 PDF 首页脚注。
- **把"标注多个基金"当拼盘**。国家级 + 省级 + 校级联合资助是常规写法。
- **忽略项目结题后的合理产出期**。结题 2 年后发表的论文不应算作该项目成果，但结题当年及次年发表的通常认可。
- **把依托单位变更当问题**。作者调动工作后，原项目成果仍可标注原单位。
- **忽略"参与人"身份**。非负责人标注他人项目，只要是参与人即合规。

## D6 成果与履历一致性

### 核查点

| 编号 | 核查内容 |
|---|---|
| D6-1 | 单位官网/申报材料所列论文是否真实存在 |
| D6-2 | 所列论文的作者位次是否与申报一致（把中间位次写成第一作者） |
| D6-3 | 所列期刊分区/影响因子是否准确（夸大分区） |
| D6-4 | 是否存在将录用未发表、投稿中论文列为已发表 |
| D6-5 | 是否存在将会议摘要、增刊列为正式论文 |
| D6-6 | 人才计划/职称材料中的"代表作"是否为其本人主导 |
| D6-7 | 学位论文与后续发表的关系（拆分发表需注明） |
| D6-8 | 获奖、专利与论文的对应关系是否成立 |

### 判定

- **A**：履历所列成果与公开数据完全对应。
- **B**：存在个别表述不严谨（如未注明共同第一作者）。
- **C**：存在实质性不符——虚构论文、篡改作者位次、虚报分区、将未发表列为已发表。
- **D**：无法获取申报材料，无法比对。

### 常见误判

- **共同第一作者标注差异**。不同单位认定口径不同，"共同一作"是否算一作存在争议，属认定问题而非造假。
- **期刊分区年份差异**。中科院分区逐年调整，用今年的分区质疑三年前的申报不合理。
- **在线发表 vs 正式见刊**。Online First 通常可计为已发表，但需注明。

## 综合定级

| 综合结论 | 条件 |
|---|---|
| 未发现异常 | **全部关键维度为 A**，且无任何 B/C/D |
| 存在需说明的疑点 | 任一维度 B，且无 C，且关键维度无 D |
| 高度可疑，建议移送核查 | 任一维度 C，或 ≥3 个维度同时 B 且指向同一问题 |
| 证据不足，建议补充核查 | **任一关键维度为 D** |

**关键维度** = D0 身份一致性、D2 专业相关性、D4 学术规范、D5 基金合规。

### 三条强制规则（不可协商）

**规则一：综合取「已核查维度」的最高档，并声明未覆盖范围**

| 情形 | 综合结论 |
|---|---|
| 任一关键维度 C | C，并注明哪些维度未核查 |
| 无 C，但有 B | B，并注明哪些维度未核查 |
| 无 B/C，但存在 D | **D（证据不足）**——不得写成"未发现异常" |
| 全部 A | A |

注意：一个维度查出硬证据，不因为另一个维度没查全就被压掉。压掉的是**结论的适用范围**，不是结论本身。所以 C 就是 C，但必须写"本结论仅覆盖基金标注，不涉及数据真实性（D4 未核查）"。

**规则二：未经核实的解释，不能用来降级**

这是本类审计最高频的假阴性来源。典型形态：

| 看到的现象 | 想当然的解释 | 这个解释核实了吗 | 正确处置 |
|---|---|---|---|
| 元数据标"中间作者" | "参与型署名，不构成问题" | 没看原文署名标注 | **不能据此降级**，应判 D |
| 论文跨专业 | "临床医生有合作很正常" | 没看合作者与贡献声明 | 可作反向证据，但不能替代核查 |
| 基金标注多个 | "联合资助很常见" | 没核对项目任务书 | 不能据此认定合规 |
| 无撤稿记录 | "没有学术不端记录" | 只查了 OpenAlex 一个源 | 最多写"未检索到" |

判据一句话：**若这个"正常解释"是推测出来的，而不是查出来的，它就不能把等级往下压。**

**规则三：D 维度的正面表述禁令**

当某维度为 D 时，该维度禁止出现任何正面表述。以下措辞全部违规：

| 违规表述 | 为什么违规 |
|---|---|
| 未发现图片复用 | 没拿到全文，不可能"发现"或"未发现" |
| 基金标注未发现问题 | 基金号没核过 |
| 经核查不构成问题 | 没核查，不能下"不构成" |
| 未发现撤稿记录 | 只查了一个源，应写"未检索到" |

正确写法："该项未核查（原因：全文获取率 30.8%），判定为证据不足。"

### 假阴性自检（定稿前必做）

学术审计最严重的错误不是误报，是**漏报被写成"没问题"**。定稿前把报告里所有正面表述摘出来，逐句问：

> 这句话是基于**实际的核查动作**，还是基于**数据的缺失**？

如果是后者，改写为"未核查"或"证据不足"。凡是"未发现 X"句式，都要能回答"你查了哪些源、查了几篇、命中多少"。

### 跨维度交叉核查（本类案件的要害）

单看每个维度都"正常"，交叉起来可能构成问题。必须做这两组交叉：

**交叉一：专业跨度 × 基金标注**
- 单独看"跨专业"：临床医生参与生物信息学合作，正常
- 单独看"挂基金"：论文标注 NSFC，正常
- 合起来看：**用 A 专业的项目经费，支撑 B 专业的论文** —— 这才是"标注无关项目成果"的定性形态

做法：把每个基金号名下挂的论文列出来，对照该项目的任务书摘要/关键词，逐篇判断是否属于项目研究范围。判据不是"学科标签是否相同"，而是"这篇论文的研究内容，是否可能是该项目任务书里承诺要做的事"。

**交叉二：作者位次 × 成果用途**
- 元数据显示"中间作者"：可能只是参与
- 但若该论文被列入**职称材料 / 结题成果 / 人才计划代表作**，则必须核对原文署名标注：是否共同第一作者、是否有同等贡献声明

OpenAlex 的 `author_position` 只有 first/middle/last 三值，**共同第一作者普遍被归为 middle**。仅凭该字段判断"参与型署名、不构成问题"，是这类审计最典型的假阴性来源。

**禁止**在综合结论中出现"构成学术不端""认定造假"等定性表述——那是学术委员会与基金委监督委员会的职权，不是审计报告的职权。
